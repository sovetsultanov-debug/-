# Saiyakat Studio — шаблоны картинок

Отдельный набор страниц (HTML + CSS + JS, без сборки) для картинок в соцсети.
К основному сайту не подключён.

## Как открыть
Самое простое — запустить локальный сервер в этой папке и открыть в браузере:

```bash
cd studio
python3 -m http.server 4280
# открыть http://localhost:4280
```

(Можно и двойным кликом по `index.html`, но тогда «Скачать PNG» у планировщика может не сработать.)

## Шаблоны

| Файл | Что делает |
|---|---|
| `poster.html` + `poster.js` | Постер 1080×1350 (Instagram 4:5): ваше фото на весь кадр, плашки сверху, метка места с линией маршрута, рукописный заголовок, кнопка-стрелка. Все тексты и 3 палитры меняются в панели справа. Фото можно двигать мышкой/пальцем. «Скачать PNG» сохраняет картинку в полном размере. |
| `planner.html` + `planner.css` + `planner.js` | Бланк «план поездки» A4 на 4 дня: место, еда, занятия, отдых, бюджет. Заполняется прямо на странице. Две темы (классика / Saiyakat), EN/RU. «Печать / PDF» и «Скачать PNG». |
| `studio.css` | Общий стиль редактора. |

## Где что менять
- Позиции элементов постера — функции `drawTopBar`, `drawLocationTag`, `drawRoute`, `drawText` в `poster.js` (координаты в пикселях холста 1080×1350).
- Форма линии маршрута — кривые `bezierCurveTo` в `drawRoute`.
- Цвета постера — объект `PALETTES` в `poster.js`.
- Цвета планировщика — блоки `.theme-classic` и `.theme-saiyakat` в `planner.css`.
- Иллюстрации планировщика (камера, пальма, самолёт, чемодан) — объект `ICONS` в `planner.js` (SVG, нарисованы кодом).

## Нужен интернет
Шрифты (Montserrat, Marck Script, Caveat) грузятся с Google Fonts, а «Скачать PNG» планировщика — библиотека html2canvas с cdnjs.
