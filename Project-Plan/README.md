## Стек одним взглядом

| Слой | Основной выбор | Альтернатива |
| --- | --- | --- |
| База данных | PostgreSQL (Supabase или Neon) с таблицами ролей | Cloudflare D1 только для мелочей |
| Бэкенд (API) | Hono + TypeScript на Cloudflare Workers | Laravel (PHP) на обычном сервере |
| Файлы | Cloudflare R2 | Supabase Storage |
| Веб-сайт | Next.js на Vercel | Cloudflare Pages |
| Мобильное приложение | React Native + Expo | Flutter (эксперимент одного человека) |
| Сборка Android | Android Studio (эмулятор, apk) | EAS Build |
| Локальная среда | Docker Compose | — |
| Отладка | Chrome DevTools (Network, Slow 4G), Postman | curl |

## Порядок работы

1. Схема базы с ролями. Без неё остальное рассыпается.
2. Один бэкенд: Hono + Cloudflare, если пишем на TypeScript, или Laravel, если ближе PHP.
3. Docker, чтобы проект разворачивался у всех одинаково.
4. Деплой: Vercel для сайта, Cloudflare для API.
5. Мобильное приложение в конце, и только одно: React Native.

## Требования к проекту

- **Аутентификация:** регистрация, вход, роли и права.
- **База данных:** создание, чтение, изменение и удаление данных.
- **Frontend:** адаптивный сайт и экраны мобильного приложения.
- **Backend:** REST API и бизнес-логика.
- **Админ-панель:** управление пользователями, услугами и записями.
- **Безопасность:** валидация входных данных, контроль доступа, секреты только в `.env`.
- **Тестирование:** функциональные тесты и обработка ошибок.
- **Документация:** описание проекта, схема базы, инструкция по запуску.
