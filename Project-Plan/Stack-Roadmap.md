## Бэкенд и данные

### 1. База данных с ролями — PostgreSQL

Схема: `users` → `user_roles` → `roles` → `role_permissions` → `permissions`.
Минимум три роли: владелец, сотрудник, клиент.

> ⚠️ **Ошибка:** хранить роль строкой в `users.role`. Тогда у человека не может быть двух ролей.

- [ ] Нарисовать схему BatTap в dbdiagram.io: businesses, users, roles, services, bookings.
- [ ] Создать таблицы в PostgreSQL миграциями, не руками.
- [ ] Написать запрос «все записи на завтра у бизнеса X» с JOIN по трём таблицам.

### 2. Laravel (альтернатива)

PHP-фреймворк: роутинг, Eloquent, авторизация, миграции из коробки. Нужен обычный сервер.

> ⚠️ **Ошибка:** учить Laravel и Hono одновременно. Выберите один бэкенд.

- [ ] `laravel new battap-api` и подключить PostgreSQL.
- [ ] Миграция и модель `Business`.
- [ ] Маршрут `GET /api/businesses/{slug}`.

### 3. Hono (основной бэкенд)

Лёгкий TypeScript-фреймворк, работает на Node, Cloudflare Workers и Vercel.

> ⚠️ **Ошибка:** принимать данные без проверки. Всё из `POST /bookings` валидировать.

- [ ] `npm create hono@latest`, шаблон cloudflare-workers.
- [ ] `GET /businesses/:slug` и `POST /bookings` с проверкой через zod.
- [ ] Проверить оба маршрута в curl или Postman, в том числе с неверными данными.

### 4. Docker

Одинаковое окружение у всех: одна версия базы и Node.

> ⚠️ **Ошибка:** пароль базы в `docker-compose.yml` в GitHub. Пароли только в `.env`.

- [ ] `docker-compose.yml` с PostgreSQL и API.
- [ ] `docker compose up` и подключение к базе из кода.
- [ ] Новый участник разворачивает проект одной командой по README.

## Инфраструктура и деплой

### 5. Cloudflare — Workers, D1, R2, Pages

> ⚠️ **Ошибка:** ждать от D1 возможностей PostgreSQL. Основная база — Supabase или Neon.

- [ ] `wrangler deploy` и открыть API по ссылке.
- [ ] Положить картинку в R2 и отдать её через Worker.
- [ ] Подключить свой домен, SSL включится сам.

### 6. Vercel

Каждый push выкладывается сам, каждая ветка получает preview-ссылку.

> ⚠️ **Ошибка:** пушить прямо в `main`.

- [ ] Подключить фронтенд к Vercel, получить рабочую ссылку.
- [ ] Ветка с изменением и её preview-ссылка.
- [ ] Адрес API — переменная окружения в Vercel, а не в коде.

### 7. DevTools и api.battap.app

Вкладка Network: каждый запрос, вес и время.

> ⚠️ **Ошибка:** проверять только на быстром Wi-Fi. Включайте «Slow 4G».

- [ ] Карточка бизнеса, фильтр Fetch/XHR, записать все запросы к API.
- [ ] Найти запрос создания брони, проверить тело и ответ.
- [ ] Убрать повторные запросы одного и того же адреса.
