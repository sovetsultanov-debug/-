# Фото для главной

Сайт ищет здесь 8 файлов (вертикальные, формат 4:5, от 1000 px в ширину):

| Файл | Где показывается |
|---|---|
| `hero-1.jpg` … `hero-4.jpg` | слайдер на главной |
| `trip-1.jpg` … `trip-4.jpg` | карточки примеров поездок (по порядку) |

Сейчас тут тестовые фото из интернета. Они **не попадают в git** (см. `.gitignore`).
Перед публикацией замените их на свои или бесплатные со стоков (Unsplash, Pexels)
с теми же именами. Если файла нет, сайт просто покажет тёмный фон.
