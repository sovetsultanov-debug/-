# kadam.kg — Единая волонтёрская платформа Кыргызстана

Современная веб-платформа **kadam.kg** («Кадам» — шаг к добрым делам) для координации волонтёрских инициатив в Кыргызстане (Бишкек, Ош, Иссык-Куль и другие регионы), записи на мероприятия, получения мгновенных уведомлений, ведения личного профиля с фотографиями и хранения верифицированных сертификатов с учётом волонтёрских часов.

---

## 🌟 Ключевые возможности

### 1. 🔔 Центр уведомлений о новых мероприятиях
- **Мгновенные оповещения**: при публикации организатором нового мероприятия система автоматически отправляет уведомление всем волонтёрам.
- **Интерактивный колокольчик в шапке**: бейдж со счётчиком непрочитанных событий, выпадающий список уведомлений с отметкой времени и кнопкой «Прочитать все».
- **Всплывающие уведомления (Toast)** и верхний информационный баннер о свежих событиях.
- Оповещения о подтверждении участия в мероприятии и начислении часов за добавленные сертификаты.

### 2. 👤 Профиль волонтёра и раздел «О себе»
- **Загрузка фотографии профиля**: поддержка загрузки любых локальных изображений (JPG, PNG, WEBP) с устройства пользователя с мгновенным предпросмотром.
- **Блок «О себе» (Bio)**: удобный редактор текста с контролем символов для описания своего опыта, мотивации и волонтёрских целей.
- **Контакты и география**: имя, город проживания, телефон (WhatsApp) и email для координаторов.
- **Навыки и направления помощи**: интерактивные теги (экология, первая помощь, работа с детьми, забота о животных, авто-волонтёрство, IT и медиа) плюс возможность добавлять собственные навыки.
- **Электронная волонтёрская книжка**:
  - Суммарный счётчик волонтёрских часов.
  - Количество подтверждённых сертификатов и посещённых событий.
  - Ранг волонтёра (*Новичок*, *Волонтёр*, *Активист*, *Лидер добра*, *Почётный волонтёр*).
- **Настройки уведомлений**: переключатели для push- и email-оповещений.

### 3. 📜 Загрузка и хранилище сертификатов
- **Загрузка сканов и фото сертификатов**: модальная форма с проверкой размера файла (до 8 МБ) и допустимых форматов.
- **Учёт волонтёрских часов**: при загрузке сертификата указывается количество часов, которые автоматически зачисляются в общий волонтёрский стаж.
- **Бейдж верификации**: визуальное подтверждение подлинности документа.
- **Полноэкранный просмотрщик**: режим детального просмотра сертификата с возможностью скачать оригинал.

### 4. 📅 Каталог мероприятий и онлайн-запись
- **Направления помощи**:
  - 🌿 *Экология* (субботники, посадка деревьев, уборка национальных парков)
  - 🐕 *Забота о животных* (выгул, социализация, помощь городским приютам)
  - 🤝 *Социальная помощь* (поддержка пожилых людей, детские дома)
  - 🏃 *Спорт* (городские марафоны, благотворительные забеги)
  - 🎭 *Культура* (фестивали, музеи, выставки)
  - 🚨 *ЧС и сбор помощи* (пункты сбора гуманитарной помощи)
- **Поиск и фильтрация**: поиск по ключевым словам, городу, названию или организатору, переключатель «Только онлайн-формат».
- **Карточки мероприятий**:
  - Обложка, дата, время и точный адрес.
  - Количество часов в волонтёрскую книжку (например, `+5 ч.`).
  - Прогресс-бар заполняемости мест (например, `25 из 35 мест`).
  - Бонусы волонтёрам: бесплатное питание, трансфер, мерч, справка для учёбы/работы.
  - Кнопка «Записаться» в один клик с мгновенным обновлением статуса.
- **Раздел «Мои записи»**: сводный список всех событий, в которых участвует волонтёр, с возможностью отмены записи.

### 5. ➕ Создание мероприятий для организаторов
- Форма добавления нового события: название, категория, дата, время, адрес, требуемое количество волонтёров, часы в книжку, список задач и загрузка обложки.
- При создании мероприятия система рассылает уведомление всем волонтёрам платформы.

### 6. 📱 Отдельная страница регистрации и входа (в стиле Instagram & Apple Pro Max)
- **Изолированный полноэкранный лендинг (Standalone Page)**:
  - Регистрация вынесена в отдельное самостоятельное веб-пространство (без внутренней шапки платформы, как на сайте Instagram).
  - Кнопка быстрого возврата «← На главную kadam.kg» и продолжения в гостевом режиме.
- **Двухколоночный макет Instagram**:
  - *Левая колонка*: реалистичный iPhone Pro с динамическим слайдером реальных волонтёрских историй и постов Кыргызстана (Ала-Арча, приют «Добрые руки», марафон Run the Silk Road), лайками, комментариями и отметками.
  - *Правая колонка*: фирменные карточки авторизации Instagram:
    - Основная карточка с логотипом `kadam.kg`, слоганом, быстрым входом через Google, разделителем `ИЛИ`, чистыми полями ввода, валидатором пароля и кнопкой «Зарегистрироваться».
    - Нижняя карточка переключения: «Есть аккаунт? **Войти**» / «У вас ещё нет аккаунта? **Зарегистрироваться**».
    - Бейджи загрузки приложения (Google Play / App Store).
- **Минималистичный подвал Instagram**: ссылки на разделы, города Кыргызстана и копирайт `© 2026 kadam.kg`.

### 7. 💾 Полное сохранение данных (LocalStorage)
- Все действия пользователя (загруженные фотографии, изменения в био, созданные сертификаты, новые мероприятия и статусы записей) надёжно сохраняются в памяти браузера и доступны после перезагрузки страницы.

## 🛠 Технологический стек

- **Фреймворк**: React 19 (Functional Components, Hooks)
- **Язык**: TypeScript 5+ (строгая типизация)
- **Стилизация**: Tailwind CSS v4
- **Иконки**: Lucide React
- **Сборщик**: Vite 6+
- **Тестирование**: Встроенный тестовый раннер Node.js (`node:test`, `node:assert/strict`)

## 🚀 Запуск и разработка

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Запуск модульных тестов
```bash
npx --yes tsx --test src/utils/volunteer-logic.test.ts
```

### Сборка для продакшена
```bash
npm run build
```
